# Static employer data removal

The committed employer configuration registry, hardcoded company profiles, curated dossiers, modeled metrics, locations, reports, bundled workbooks, and automatic workbook-loading path were removed from the active repository tree.

The remaining data-layer code is runtime-only. Employer-specific intelligence must be initiated through an explicit manual public-source workflow.

This cleanup does not rewrite Git history. Earlier commits may still contain removed files until a separate history-purge operation is explicitly approved.
